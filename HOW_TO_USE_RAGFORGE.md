# How to use RAGForge

## First time

```bash
git clone -b dev https://github.com/janarddansarkar/RAGFORGE.git
cd RAGFORGE
./setup.sh
./run.sh
```

Open http://localhost:8501

## Next times

```bash
cd RAGFORGE
./run.sh
```

## Update to the latest version

```bash
cd RAGFORGE
git pull
./setup.sh
./run.sh
```
